# Screenshot sources

These are unedited screenshots captured on 2026-11-06 from the official public Ant Design Pro demo, using its example data. They illustrate the template and are not mockups of any private project.

- Source: https://preview.pro.ant.design/list/table-list/
- Observed demo footer: version 6.0.1, commit `2db826cb350e46206252197f416a0a22f2b9bbfe`.
- `table-compact.jpg`: the Compact density option selected.
- `columns-hidden.jpg`: the Description column hidden through the built-in column chooser.
- `detail-drawer.jpg`: the record detail drawer opened from the list.

Ant Design Pro source: https://github.com/ant-design/ant-design-pro
